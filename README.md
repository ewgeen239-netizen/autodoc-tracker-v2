# AutoDoc Tracker v2

Telegram Mini App и бот для склада AutoDoc M13 Outbound, Szczecin: пики и премия по таблицам OS, PA, SIO, PC, PLC и ещё 7 станций Inbound и Załadunek, график смен DARK / ORANGE / GREEN по группам A–F, кошелёк с зарплатой на руки по польским ставкам 2026 года и оповещения в Telegram.

Новая версия проекта [ewgeen239-netizen/test](https://github.com/ewgeen239-netizen/test): новый дизайн, исправленный расчёт зарплаты, рабочие оповещения, без игр.

## Что внутри

| Файл | Что делает |
|---|---|
| `index.html`, `assets/` | Mini App (GitHub Pages). `core.js` — вся математика, `slip.js` — чтение odcinka (PDF), `app.js` — интерфейс. |
| `schedule.json` | Единый график смен. Его читают и приложение, и бот. Правишь только его. |
| `bot.py` | Бот: меню, смены, оповещения, рейтинг, расчёт премии, админ-команды. |
| `shifts.py` | График, хранилище Supabase, планировщик оповещений (чистые функции + тесты). |
| `supabase/schema.sql` | Схема базы. Идемпотентная: доводит старую базу до новой, данные не стирает. |
| `supabase/functions/api/` | Edge Function: проверка подписи Telegram, рейтинг, профиль оповещений, лента `.ics`, даты зарплаты, статистика Indirect. `python3 tools/bundle_api.py` собирает `index.bundled.ts` для редактора Supabase. |
| `tests/` | `node tests/core.test.mjs`, `node tests/slip.test.mjs`, `node tests/api.test.mjs`, `python -m unittest discover tests`. |

## Как считается

**Премия.** Все пики и часы станции за месяц → средний темп → ступень ставки → (пики − норма) × ставка. Ночная смена 22:00–06:00 принадлежит дню, в который началась.

- **Свои станции.** Работник сам выбирает 3–5 рабочих мест (конструктор на «Пиках», в профиле и в таблицах ставок) — они висят кнопками сверху, остальные под «Дополнительно». По умолчанию OS, PA, SIO, PC, PLC.
- **Дополнительные станции**: PI Picking Inventory (норма 160), OP Oversize Placement (144), HR Direct Receive High Rack (140), DP Disassembly Pallet (165), ROD Receiving On Demand (165), POD Putwall On Demand (212) — по штукам сверх нормы; ZK Załadunek kontenerów — по Aneksowi 2/2026 с 01.06.2026: норма 100 пачек/ч, премия = часы на станции × ставка за час (8,92–20,83 zł).

**Премия Indirect.** Плашка на главной под премией: сумма премии Indirect из pasku и часы на Indirect за месяц. Трекер считает ставку за час, добавляет премию в брутто кошелька и отправляет сумму с часами (без имени) на сервер — оттуда приходит средняя ставка Indirect за час по складу и медиана по людям.

**Проверка odcinka.** Кнопка на главной под премией. PDF odcinka płacowego (Streamsoft) разбирается прямо на телефоне — файл никуда не уходит. Проверяются: часы × ставка, ночная доплата 20% от минимальной часовой, сверхурочные, отпускные, ZUS 13,71%, składka zdrowotna 9%, PIT (ulga dla młodych, PIT-2), «на руки». Премия сверяется с пиками в трекере (с обецностью), часы — с графиком. Korekty складываются с главным листом. Сумма из odcinka встаёт в «Прошлые выплаты» нужного месяца (расчёт трекера остаётся рядом для сравнения), ставку, эквиваленты и удержания можно перенести в кошелёк одной кнопкой.

**Дата зарплаты.** До 10-го числа; если 10-е — выходной или праздник, то последний рабочий день перед ним; если накануне рабочий день не раньше 8-го — 80% на день раньше, 100% к сроку. Люди отмечают в odcinku, когда пришли деньги; Edge Function хранит только дату (`paydays`) и отдаёт счётчики по датам — прогноз уточняется. Метка «zł» стоит в календаре графика.

**Зарплата (umowa o pracę, 2026).** Брутто = часы × ставка + отпуск + ночная доплата 20% + сверхурочные (+50% / +100%) + премия за пики + прочие доплаты. Дальше ZUS 13,71%, składka zdrowotna 9% от (брутто − ZUS), PIT 12% от (брутто − ZUS − KUP 250/300 zł) минус 300 zł при PIT-2, PPK по желанию. Для минималки 4806 zł выходит 3605,85 zł на руки — так же, как в польских калькуляторах.

- **Возраст.** Работник вводит дату рождения и подтверждает её галочкой. До 26 лет PIT = 0 (ulga dla młodych). Без подтверждения налог считается как для 26+. Дата рождения не уходит на сервер.
- **Ночная доплата.** По Kodeks pracy — 20% от минимальной часовой (4806 zł / номинальные часы месяца). Если AutoDoc платит от своей ставки — переключатель в кошельке.
- **Статьи AutoDoc.** Ставка по умолчанию 33,00 zł/ч, Dodatek DARK 300 zł за полный месяц смен (брутто, облагается), эквивалент за одежду и стирку 22,95 zł (без налога, сразу в «на руки»), поле для удержаний (benefit и т.п.). Ночная доплата — 20% от минимальной часовой (4806 zł / номинальные часы месяца). Формула проверена на реальных paskach до копейки.
- **Премия за обецность.** Без пропусков премия ×1,25, с одним пропуском ×0,8, с двумя и больше премии нет. Пропуски отмечаются в календаре, кошелёк считает их сам, число можно поправить.
- **Лимит ulga dla młodych.** 85 528 zł в год: доход с начала года берётся из прошлых выплат кошелька (можно поправить), сверх лимита PIT считается.
- **Отпуск (urlop).** Час отпуска = ставка + средняя переменная часть за 3 месяца по дате выплаты, то есть работа за месяцы −4…−2 (премия, сверхурочные целиком, ночные и Dodatek DARK ÷ отработанные часы со сверхурочными), как в rozporządzeniu o urlopach. Берётся из сохранённых расчётов прошлых месяцев, а если их нет — оценивается по графику, календарю сверхурочных и архиву премий. Значение можно поправить руками. Часы отпуска — по длине смены в отмеченный день.
- **Цикл кошелька.** До 10-го числа виден расчёт за прошлый месяц, с 10-го — за текущий. Сохранённый расчёт держится до 10-го следующего месяца, потом уходит в «Прошлые выплаты». Премия пересчитывается при каждом входе в кошелёк.

## Безопасность

- Загрузчик проверяет среду Telegram, затем сервер проверяет HMAC-подпись `initData` и возвращает доверенный id. Чужие данные на устройстве не показываются.
- Запись в базу — только через Edge Function и только с верной подписью; uid берётся из подписи, неправдоподобные итоги (премия больше пики × 0,74 и т.п.) отклоняются, частые запросы режутся.
- Telegram ID в рейтинге больше не читаются публичным ключом — вместо них непрозрачный `pub`.
- Строгая CSP, никаких inline-скриптов, всё пользовательское экранируется.
- Данные приложения: localStorage + резервная копия в облаке Telegram (CloudStorage) — восстанавливаются на новом телефоне.
- Odcinek не покидает телефон: на сервер уходит только дата прихода зарплаты, без сумм; наружу — только сколько человек отметили какую дату.
- Бот хранит всё в Supabase (Railway стирает файлы при редеплое), экранирует HTML, ограничивает частоту запросов.

## Оповещения

Бот раз в минуту смотрит смены и шлёт: за 2 часа, за час, «запиши пики» через 15 минут после конца смены, 10-го числа — «кошелёк обновился». Каждое уходит ровно один раз (`notify_log`), даже после перезапуска. Смену и группу человек выбирает при первом входе — в приложении или в боте; дни отпуска из календаря приложения бот пропускает.

## Деплой

### 1. База (та же, что на проде)

Supabase → SQL Editor → выполни `supabase/schema.sql`. Старые таблицы и данные остаются, добавляются колонки и `notify_log`.

> Скрипт закрывает колонку `uid` рейтинга от публичного ключа. Старая версия приложения после этого не покажет рейтинг — переключи бота на новый `WEBAPP_URL`.

### 2. Edge Function

```bash
supabase link --project-ref mkuwkntdcpfsxhqblkic
supabase functions deploy api --no-verify-jwt
supabase secrets set BOT_TOKEN=... PROJECT_URL=https://mkuwkntdcpfsxhqblkic.supabase.co SERVICE_ROLE_KEY=... PUB_SALT=... ALLOWED_ORIGINS=https://<user>.github.io
```

Через браузер: Edge Functions → создать `api` → вставить `index.ts` и `ics.ts` → выключить Verify JWT → Secrets.

**Подтверждение аккаунтов.** Mini App подписан токеном бота, из которого его открыли. Функция принимает подпись по `BOT_TOKEN` и, через запятую, по `BOT_TOKENS` — так работают и старый, и новый бот. Если в боте `/check` (или лог Railway при запуске) пишет «НЕ принимает подпись», добавь в Supabase → Edge Functions → Secrets `BOT_TOKENS` = токен бота из Railway `TOKEN`. В приложении статус виден в шапке (зелёная точка) и в «Ещё → Профиль».

### 3. Mini App

GitHub → Settings → Pages → Deploy from branch `main`, папка `/`. Адрес вида `https://<user>.github.io/<repo>/`. Ключи Supabase — в `assets/js/config.js`.

**Обновление приложения.** Telegram кэширует файлы, поэтому после правок в `assets/` запусти `python3 tools/bump_version.py` и закоммить. Приложение при запуске сверит версию с `version.json` и само перезагрузится на новую.

### 4. Бот на Railway

New Project → Deploy from GitHub → этот репозиторий. Variables — из `.env.example`. В @BotFather для Mini App укажи тот же `WEBAPP_URL`.

## Команды бота

`/start`, `/today`, `/week`, `/month`, `/team`, `/notify`, `/rating`, `/calc os 420 8`, `/pay`, `/calendar`, `/id`.
Админ (список — `/admin`, в меню «/» видят только админы из `ADMIN_TELEGRAM_IDS`):

| Команда | Что делает |
|---|---|
| `/nstatus` | работает ли рассылка, последний круг, сколько ушло за сутки по видам, ошибки |
| `/nplan [часы]` | кому и какие оповещения уйдут в ближайшие часы |
| `/nlog [N]` | последние отправленные оповещения |
| `/nuser <id>` | настройки человека, смена, отпуск, ближайшие смены, что ему уходило |
| `/ntest` | прислать себе все четыре вида оповещений |
| `/nsend dark A текст` | сообщение смене или группе (`all` — всем), с предпросмотром и подтверждением |
| `/npause`, `/nresume` | остановить и вернуть рассылку (пауза снимается при перезапуске) |
| `/rebuild [id\|all]` | пересобрать графики из `schedule.json` |
| `/stats`, `/broadcast`, `/shift_add`, `/shift_del`, `/shift_who` | статистика, рассылка всем, ручные смены |
